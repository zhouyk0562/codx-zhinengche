# 旧电机代码

本目录保存旧电机时期建立的工程，便于回顾和对照参数：

| 工程 | 用途 |
|---|---|
| `DianJi_PI_SuDu_Huan_WiFi_CeShi` | 旧电机速度 PI、堵转保护和 WiFi |
| `DianJi_JieKou1_WiFi_CeShi` | 旧电机接口和编码器联调 |
| `ZiTai_SuDu_Kong_Zhi_WiFi_CeShi` | 旧电机姿态坡度调速 |
| `BianMaQi_JieKou1_WiFi_CeShi` | 旧阶段编码器与 WiFi 测试 |
| `BianMaQi_JieKou1_PingMu_CeShi` | 旧阶段编码器与屏幕测试 |

这些工程保留原参数，不再作为当前新电机的最终工程。
