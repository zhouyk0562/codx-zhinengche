# 新电机姿态调速工程

本工程用 IMU963RA 融合计算车辆坡度角，再把坡度转换为动态目标轮速，并通过新电机速度 PI 控制电机。

## 控制流程

```text
IMU963RA 九轴数据
    -> 姿态解算
    -> 上电姿态零点
    -> 基础车速加坡度补偿
    -> 速度 PI
    -> 电机 PWM 和方向
```

## 定时周期

- IMU 采集和姿态计算：20 ms
- 电机速度控制：50 ms
- 两个周期独立，不改变原速度 PI 的 50 ms 采样时间

## 坡度控制

- 默认使用 `Roll`；
- 上电后自动采集 20 个姿态样本确定零点；
- 水平路面基础目标为 `250 RPM`；
- 坡度死区为 `±1°`；
- 上坡每度增加 `6 RPM`，下坡每度减少 `6 RPM`；
- 目标轮速限制在 `100～300 RPM`；
- 当前安装方向相反时，把 `ZI_TAI_PO_DU_FANGXIANG` 改成 `-1.0f`。
- 目标轮速每 50 ms 最多变化 `20 RPM`，避免电机响应过于突然。

参数位于 `user/inc/XitongPeiZhi.h`。

这里的角度来自陀螺仪和加速度计的互补滤波。陀螺仪负责快速响应转动，加速度计负责长期修正坡度角，不能只使用陀螺仪原始角速度判断固定坡度。

## 新电机速度环

```text
启动脉冲：12%，最多约 0.6 秒
启动完成条件：实际轮速达到 100 RPM
基础前馈：5.0%
速度前馈：每 RPM 增加 0.01%
Kp：1.5
Ki：0.5
测速滤波：0.8 × 旧值 + 0.2 × 新值
PWM 上限：15%
```

## 堵转保护

- PWM 达到 `8%`、实际轮速低于 `20 RPM` 连续 `5` 个控制周期时判定堵转；
- 堵转后立即关闭 PWM，等待 `60` 个周期，约 `3 秒`后允许重新启动；
- 正常上坡、下坡都执行堵转检测。

## 新电机实测

```text
倾斜范围：约 -17°～+55°
目标轮速范围：100～400 RPM
目标 400 RPM 时：实际约 399～417 RPM
目标 155～173 RPM 时：实际约 138～201 RPM
堵转异常：0 次
WiFi：持续发送成功
```

## VOFA+ 数据

```text
ZiTai:坡度角,目标轮速,实际轮速,PWM占空比,编码器RPM,堵转状态
```

堵转状态：

```text
0 = 正常
1 = 堵转保护中
```
