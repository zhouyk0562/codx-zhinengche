# 新电机速度闭环测试

本工程用于重新整定新电机的低速速度环。控制目标为 `250 RPM`，暂时不包含 IMU、WiFi 和反转控制。

## 控制流程

```text
编码器脉冲
    -> 编码器转速
    -> 齿轮比换算轮速
    -> 速度 PI
    -> PWM
```

新电机实测表明，正转时编码器原始脉冲为负。由于本阶段只控制正转，速度反馈使用绝对脉冲数。

## 初始参数

```text
目标轮速：250 RPM
Kp：1.0
Ki：0.5
固定前馈：7.5%
积分初值：0
PWM 上限：15%
控制周期：50 ms
```

设置积分初值是为了帮助新电机越过静摩擦，避免目标只有 150 RPM 时长时间不启动。

## 堵转保护

```text
启动屏蔽：1 秒
PWM 达到 13%
实际轮速低于 30 RPM
连续 5 个控制周期
保护后等待 60 个周期，约 3 秒
```

## 串口数据

```text
DIANJI target=目标轮速 actual=实际轮速 duty=PWM enc=编码器RPM stall=堵转状态
```

## WiFi 和 VOFA+

连接方式：

```text
协议：FireWater
连接：TCP Server
端口：8086
```

WiFi 数据格式：

```text
DianJi:目标轮速,实际轮速,PWM占空比,编码器RPM,堵转状态
```

WiFi 初始化只重试 3 次。模块未连接或热点不可用时，程序会继续运行并保留串口输出，不会卡死在 WiFi 初始化。

## 当前 WiFi 状态

2026-10-31 实测时 WiFi SPI 初始化返回 `1`，没有检测到 WiFi 模块，因此尚未完成无线数据接收验证。需要检查模块 `5V、GND、MISO、SCK、MOSI、CS、INT、RST` 接线和供电。

由于新电机 15% 空载可达约 1100～1200 RPM，第一次测试必须让车轮悬空，并限制 PWM 不超过 15%。

## 实测结果

```text
目标轮速：250 RPM
稳态平均轮速：250.3 RPM
稳态波动标准差：约 5.43 RPM
稳态主要范围：约 238～266 RPM
误堵转：0 次
```

新电机在 150 RPM 附近接近静摩擦边界，会出现启动后再次停住。最终测试目标改为 250 RPM，并使用 11% 短时启动脉冲。当前 PI 参数在 250 RPM 工作点启动快、无持续超调，可以连续运行。
