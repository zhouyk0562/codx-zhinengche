# 电机开环正反转测试

本工程用于更换电机后确认驱动板、电机接线、转向、启动占空比和编码器反馈，不包含 PID 或 WiFi。

## 自动测试流程

```text
停车 1 秒
正转：0～15% 缓慢升速，保持约 2 秒
停车 1 秒
反转：0～15% 缓慢升速，保持约 2 秒
停车 1 秒
循环
```

PWM 每 50 ms 增加 1%，不会从 0 直接跳到 15%。

## 状态编号

```text
0 = 正转前停车
1 = 正转升速
2 = 正转保持
3 = 反转前停车
4 = 反转升速
5 = 反转保持
6 = 回到正转前停车
```

串口输出格式：

```text
KAIHUAN state=状态 dir=方向 duty=占空比 pulse=脉冲 enc=编码器RPM wheel=估算轮速
```

`dir=0` 表示正转，`dir=1` 表示反转。

正转时脉冲和轮速应为正，反转时应为负。如果只出现零或方向与驱动方向不一致，先检查编码器接线和方向线。

## 当前新电机实测

```text
驱动正转 dir=0：编码器脉冲为负
驱动反转 dir=1：编码器脉冲为正
15% 占空比空载：约 1100～1200 RPM
```

因此编码器反馈方向与电机驱动方向相反。后续恢复速度闭环时，需要使用修正后的编码器速度符号。

## 安全要求

- 第一次下载时车轮必须悬空；
- 手边必须能随时关闭电池或电机驱动电源；
- 如果 15% 仍不能启动，先关闭电源，再逐级提高 `KAIHUAN_ZUI_DA_ZHANKONGBI`；
- 如果电机声音、驱动板温度或转动状态异常，立即断电。
